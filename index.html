How to Play Call Break

♠ Trump Suit

Spades (♠) are always the permanent Trump suit in Call Break. A Spade beats any card of other suits.

🎯 Bidding Phase

At the start of each round, players bid (call) between 1 and 13 expected tricks they plan to win. Minimum bid is 1.

🃏 Playing Rules

  • You must follow the lead suit played in the trick if you have it.
  • You must play a card of higher rank than the highest card played so far if possible.
  • If you don't have the lead suit, you must play a Spade (trump) if available.
  • If you have neither the lead suit nor a winning spade, you can throw any card.

📊 Scoring System

• If tricks won = Bid: Score = Bid (e.g., Bid 3, Won 3 = 3.0 points)

• If tricks won > Bid: Score = Bid + 0.1 for each extra trick (e.g., Bid 3, Won 5 = 3.2 points)

• If tricks won < Bid: Score = -Bid (Negative penalty, e.g., Bid 4, Won 2 = -4.0 points)
